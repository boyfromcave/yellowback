importprivkey "zcashprivkey" ( "label" rescan )

Adds a private key (as returned by dumpprivkey) to your wallet.

Arguments:
1. "zcashprivkey"   (string, required) The private key (see dumpprivkey)
2. "label"            (string, optional, default="") An optional label
3. rescan               (boolean, optional, default=true) Rescan the wallet for transactions

Note: This call can take a long time to complete if rescan is true.

Examples:

Dump a private key
> ycash-cli dumpprivkey "myaddress"

Import the private key with rescan
> ycash-cli importprivkey "mykey"

Import using a label and without rescan
> ycash-cli importprivkey "mykey" "testing" false

As a JSON-RPC call
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "importprivkey", "params": ["mykey", "testing", false] }' -H 'content-type: text/plain;' http://127.0.0.1:8832/
