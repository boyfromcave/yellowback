z_exportivk "zaddr"

Reveals the Sapling incoming viewing key corresponding to 'zaddr'.
Use z_importivk to re-import the resulting key.

Arguments:
1. "zaddr"   (string, required) The Sapling zaddr for the viewing key

Result:
"ivk"        (string) The bech32-encoded Sapling incoming viewing key ("zivks...")

Examples:
> ycash-cli z_exportivk "ys1z7rejlpsa98s2rrrfkwmaxu53e4ue0ulcrw0h4x5g8jl04tak0d3mm47vdtahatqrlknghgfflq"
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "z_exportivk", "params": ["ys1z7rejlpsa98s2rrrfkwmaxu53e4ue0ulcrw0h4x5g8jl04tak0d3mm47vdtahatqrlknghgfflq"] }' -H 'content-type: text/plain;' http://127.0.0.1:8832/
