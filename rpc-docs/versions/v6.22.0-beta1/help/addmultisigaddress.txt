addmultisigaddress nrequired ["key",...] ( "" )

Add a nrequired-to-sign transparent multisignature address to the wallet.
Each key is a transparent Ycash address or hex-encoded secp256k1 public key.

Arguments:
1. nrequired        (numeric, required) The number of required signatures out of the n keys or addresses.
2. "keysobject"   (string, required) A json array of Ycash addresses or hex-encoded public keys
     [
       "address"  (string) Ycash address or hex-encoded public key
       ...,
     ]
3. (dummy)        (string, optional) DEPRECATED. If provided, MUST be set to the empty string "".
Result:
"zcashaddress"  (string) A Ycash address associated with the keys.

Examples:

Add a multisig address from 2 addresses
> ycash-cli addmultisigaddress 2 "[\"s1YdUEzTzjYawpW8wkRjwa6tKJPYPvu3CwB\",\"s1hfWJ4ej1H3s8XCUb7YnrU68K64AsGVUHE\"]"

As json rpc call
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "addmultisigaddress", "params": [2, "[\"s1YdUEzTzjYawpW8wkRjwa6tKJPYPvu3CwB\",\"s1hfWJ4ej1H3s8XCUb7YnrU68K64AsGVUHE\"]"] }' -H 'content-type: text/plain;' http://127.0.0.1:8832/
