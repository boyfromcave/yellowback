importwallet "filename"

Imports taddr keys from a wallet dump file (see z_exportwallet).

Arguments:
1. "filename"    (string, required) The wallet file

Examples:

Dump the wallet
> ycash-cli z_exportwallet "nameofbackup"

Import the wallet
> ycash-cli importwallet "path/to/exportdir/nameofbackup"

Import using the json rpc call
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "importwallet", "params": ["path/to/exportdir/nameofbackup"] }' -H 'content-type: text/plain;' http://127.0.0.1:8832/
