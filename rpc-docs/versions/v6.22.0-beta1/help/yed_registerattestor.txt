yed_registerattestor bondYec lockBlocks ( flags )

Join the YED attestor set (P4-b: the attestor registry is the vault primitive's set attestorSetId) with a fresh
wallet key as the member key: set_join attestorSetId bondYec (tip + 1 + lockBlocks). vout[0] is the bond
P2SH(<bondLocktime> CLTV DROP <memberKey> CHECKSIG); the member key signs price attestations and receives the
attestor fee, so back up wallet.dat. seq is null until the join confirms (yed_listattestors). Refused with
bond-below-min, lock-below-min (the module's floor: yed_getinfo params.attest.bondMinZat, D-Q-30, and BOND_MIN_LOCK) and yellowback-no-attestor-set; a set
that is not open needs admission signatures (register-needs-admission: finish with set_signact / set_sendact).
The minimum follows the YEC locked in YED vaults at the snapshot before the join's block (D-Q-30), so post headroom: a
bond within 10% of params.attest.bondMinZat (and below bondMinCapZat) returns warning "bond-near-min"; if vault
collateral grows before it confirms, the join becomes invalid (attestor-bond-below-min) and is not mined.

Arguments:
1. bondYec     (numeric, required) the bond in YEC (>= the module's bondMinZat at the next block and the set's bondmin)
2. lockBlocks  (numeric, required) >= BOND_MIN_LOCK and the set's bondlockmin; bondLocktime = tip + 1 + lockBlocks
3. flags       (numeric, optional, default 0) accepted for compatibility and ignored (no longer recorded)

Result: { "txid", "seq", "attestorPubKey", "bondAddress", "bondKeyAddress", "bondOutpoint", "bondZat", "bondLocktime", "flags", "maturesAt", "warning" }
