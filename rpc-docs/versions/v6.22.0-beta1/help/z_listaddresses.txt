z_listaddresses ( includeWatchonly )

z_listaddresses is DEPRECATED and will be removed in a future release.
Please use `listaddresses` instead.

Returns the list of shielded addresses belonging to the wallet.

This never returns Unified Addresses; see 'listaddresses' for them.

Arguments:
1. includeWatchonly (bool, optional, default=false) Also include watchonly addresses (see 'z_importviewingkey')

Result:
[                     (json array of string)
  "zaddr"           (string) a zaddr belonging to the wallet
  ,...
]

Examples:
> ycash-cli z_listaddresses 
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "z_listaddresses", "params": [] }' -H 'content-type: text/plain;' http://127.0.0.1:8832/
