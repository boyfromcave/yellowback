listaccounts ( minconf includeWatchonly )

listaccounts is DEPRECATED and will be removed in a future release.


Returns a JSON object with account names as keys and balances as values.
Ycash emulates a single default account, so the result always has exactly
one key: "".

Arguments:
1. minconf          (numeric, optional, default=1) Minimum confirmations.
2. includeWatchonly (bool, optional, default=false) Include watch-only addresses.

Result:
{                      (json object where keys are account names, and values are amounts)
  "": x.xxx,           (numeric) The default account's confirmed transparent balance.
}

Examples:
> ycash-cli listaccounts 
> ycash-cli listaccounts 6
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "listaccounts", "params": [6] }' -H 'content-type: text/plain;' http://127.0.0.1:8832/
