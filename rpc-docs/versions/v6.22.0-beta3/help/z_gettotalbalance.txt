z_gettotalbalance ( minconf includeWatchonly )

Supported on Ycash. Its upstream replacement, z_getbalanceforaccount, needs
NU5, which has no activation height on Ycash.

Return the total value of funds stored in the node's wallet.

CAUTION: If the wallet contains any addresses for which it only has incoming viewing keys,
the returned private balance may be larger than the actual balance, because spends cannot
be detected with incoming viewing keys.

Arguments:
1. minconf          (numeric, optional, default=1) Only include private and transparent transactions confirmed at least this many times.
2. includeWatchonly (bool, optional, default=false) Also include balance in watchonly addresses (see 'importaddress' and 'z_importviewingkey')

Result:
{
  "transparent": xxxxx,     (numeric) the total balance of transparent funds
  "private": xxxxx,         (numeric) the total balance of shielded funds (in all shielded addresses)
  "total": xxxxx,           (numeric) the total balance of both transparent and shielded funds
  "transparent_ecc": xxxxx, (numeric) transparent minus transparent_pq: every output of transparent that is not
                             post-quantum (P2PKH, P2PK, P2SH; with includeWatchonly any other watched script)
  "transparent_pq": xxxxx,  (numeric) the part of transparent held by post-quantum addresses (TX_PQPKH)
  "pq_by_scheme": [         (array) transparent_pq by scheme, both schemes always
    {
      "pqscheme": n,            (numeric) 1 or 2
      "pqschemename": "name",   (string) "SLH-DSA-SHA2-128s" (1) or "FN-DSA-512" (2)
      "transparent_pq": xxxxx   (numeric) this scheme's part of transparent_pq
    }, ...
  ]
}

Every figure counts an output by its confirmations alone: at minconf 1 (the default) an unconfirmed output
is left out even when it is this wallet's own change (getwalletinfo's balance counts that); minconf 0 counts
every unconfirmed output. Coins locked with lockunspent and immature coinbase are left out; includeWatchonly
adds watch-only coins (getwalletinfo counts locked coins and never watch-only ones). Post-quantum coins are
transparent: transparent = transparent_ecc + transparent_pq, each split counted by the same rule.
The amounts are strings, as transparent, private and total are.

Examples:

The total amount in the wallet
> ycash-cli z_gettotalbalance 

The total amount in the wallet at least 5 blocks confirmed
> ycash-cli z_gettotalbalance 5

As a JSON RPC call
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "z_gettotalbalance", "params": [5] }' -H 'content-type: text/plain;' http://127.0.0.1:8832/
