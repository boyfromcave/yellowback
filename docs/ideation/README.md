# `docs/ideation/`

**Experimental ideas. Not plans. Nothing here is scheduled, funded or being built.**

Ideas are kept off `main` so the default branch holds only what is designed, delivered or in
implementation. Each idea lives on its own `ideation/*` branch, which is where it is read,
discussed and, if adopted, turned into a plan under [`../plans/`](../plans/):

| Branch | Idea | Status |
|---|---|---|
| `ideation/interoperability` (`docs/ideation/yellowback-interoperability-plan.md` there) | YED beyond Ycash: what an indexer service and a bridge would need from the `yed_*` index | inactive; written against the v2 index, no phase depends on it |
| (none: promoted directly) | YED and Wrapped Ycash on one agnostic lock/unlock primitive, two applications, one YED rule module | **promoted to [`../plans/yellowback-upgrade-plan.md`](../plans/yellowback-upgrade-plan.md) on 2026-10-05**, the day it was drafted; no ideation branch was kept |

To propose one: branch `ideation/<name>` from `main`, add the document under `docs/ideation/`
on that branch, and list it here in a pull request to `main`.
